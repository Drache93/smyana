## A first-time player, played by an agent

Dominic asked for it. A separate agent plays the game cold after each major change: it sees only screenshots and uses
only a player's mouse and keys, and knows nothing of the code or the design. Since it cannot hear or feel the clock,
the game gives it a timed log with every picture: the real minutes passed, the track playing and what it is like, each
sound as it happens, how long each march and night lasts. It reports on clarity, pace, dead stretches, how the cues
would fit and feel, and whether it had a reason to go on. Monday morning (a baseline), Friday (the opening), Saturday
(the whole run and the ending), Sunday (the build to submit).
